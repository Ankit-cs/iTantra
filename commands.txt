====================================================================
  iTantra App - Wireless Debugging & Execution Commands Guide
====================================================================

PREREQUISITES:
1. Ensure your Android device has Developer Options enabled and Wireless Debugging turned ON.
2. Ensure ADB is in your system PATH or open terminal from:
   C:\Users\Ankit\AppData\Local\Android\Sdk\platform-tools

--------------------------------------------------------------------
STEP 1: Verify Connected Device over Wireless ADB
--------------------------------------------------------------------
Run this command in terminal to confirm your phone is connected:

adb devices

(You should see your phone listed, e.g. "192.168.x.x:5555  device")

If pairing wirelessly for the first time:
adb pair <ip>:<port> <pairing-code>
adb connect <ip>:<port>

--------------------------------------------------------------------
STEP 2: Build the Debug APK
--------------------------------------------------------------------
Open PowerShell / CMD in C:\_sih2026\deploy and run:

.\gradlew.bat assembleDebug

--------------------------------------------------------------------
STEP 3: Install APK to Connected Wireless Device
--------------------------------------------------------------------
Run this command to build and install the app on your phone:

.\gradlew.bat installDebug

--------------------------------------------------------------------
STEP 4: Launch the App on Your Device
--------------------------------------------------------------------
Run this command to open the app on your phone:

adb shell am start -n com.aistudio.itantra.isro/com.example.MainActivity

--------------------------------------------------------------------
ALL-IN-ONE COMMAND (Build + Install + Launch in 1 Step)
--------------------------------------------------------------------
.\gradlew.bat installDebug ; adb shell am start -n com.aistudio.itantra.isro/com.example.MainActivity

--------------------------------------------------------------------
STEP 5: View Live App Logs (Optional / Debugging)
--------------------------------------------------------------------
adb logcat --pid=$(adb shell pidof -s com.aistudio.itantra.isro)
